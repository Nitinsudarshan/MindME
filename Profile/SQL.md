# SQL

## Summary

SQL is currently a **developing** technical competency for me rather than one of my most mature skills, with a deliberate learning/practice plan behind it.

## Where I am now

`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, aggregations, `JOIN`s, filtering, subqueries, data analysis, relational thinking, database querying.

## Where I'm building toward

```mermaid
flowchart LR
    A[SELECT / filtering / joins] --> B[CTEs]
    B --> C[Window functions]
    C --> D[Analytical SQL]
    D --> E[Query optimization]
    E --> F[Production data analysis]
```

CTEs, window functions, advanced JOIN patterns, query optimization, data modelling, analytical SQL, cohort analysis, time-series analysis.

## Why this matters for me specifically

SQL fits naturally into work I'm already doing — alumni datasets, operational databases, KPIs, dashboards, program outcomes, cohorts, placements, engagement. I'm learning it in a context where I'll actually use it immediately, not as an abstract exercise.

## My Take

I'd rather be honest that this is `seedling`/`growing`, not `evergreen` — the SELECT/JOIN/GROUP BY layer is solid, but the analytical layer (window functions, CTEs, query optimization) is the actual gap between where I am and being able to do production data analysis unassisted. This is one to revisit and re-promote in status as it firms up, per [[08 - Review and Maintenance Cadence]].
