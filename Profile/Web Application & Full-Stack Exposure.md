# Web Application & Full-Stack Exposure

## Summary

I have meaningful exposure to modern web application architecture — **Intermediate / product-builder level**, not deep frontend engineering.

## Technologies

Next.js, the React ecosystem, the JavaScript/TypeScript ecosystem, Tailwind CSS, Supabase, APIs, Git/GitHub, Vercel.

## Where my strength actually sits

I'm stronger at the application/product architecture layer than at low-level frontend engineering:

```mermaid
flowchart LR
    A[Frontend] --> B[Application logic]
    B --> C[API]
    C --> D[Database]
    D --> E[Automation]
    E --> F[Reporting]
```

## Example: NGConnect

I've worked on defining application roles, the alumni directory, CRM, job board, impact dashboard, database, imports, data ownership, and automation for NGConnect — the product decisions, not the component-level React code.

## My Take

The honest framing: I can communicate effectively with developers and reason about how an operational requirement translates into application functionality, because I understand the whole chain in the diagram above. What I can't yet do unassisted is the frontend implementation itself — that's exactly why [[Git, GitHub & Vercel]] and [[APIs & Integrations]] matter more to me than component-level React skill does.
