# Tag Index

The controlled vocabulary for `tags:` frontmatter, per [[04 - Tagging]]. Add a tag here in the same commit that introduces it in a note — that's what stops `#llm`/`#LLMs`/`#large-language-models` from silently forking into three tags for one idea.

---

## Domain

| Tag | Used for |
|---|---|
| `mnemos` | The Mnemos project itself |
| `second-brain` | PKM / second-brain concepts and research |
| `pkm` | Personal knowledge management tooling and methods |
| `obsidian` | Obsidian-specific mechanics (plugins, vault behavior) |
| `research` | Structured research/survey output |
| `dev` | Development setup, tooling, runbooks |

## Cross-cutting

| Tag | Used for |
|---|---|
| `rules` | This Rules folder |
| `meta` | Notes about the vault itself, not its content |
| `template` | Reusable templates and frameworks |
| `framework` | Structured methodologies (e.g. the repo research framework) |
| `reference` | General reference material |
| `clippings` | Web-clipper output |

## Process / maturity signals (not a substitute for `status:`)

| Tag | Used for |
|---|---|
| `idea` | Early, unshaped thinking |
| `draft` | In-progress writing |
| `planning` | Roadmap/scoping notes |
| `survey` | Comparative research output |
| `runbook` | Step-by-step operational instructions |
