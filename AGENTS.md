# Agent Instructions — MindME Vault

This is an Obsidian vault, not a code project. Before creating, editing, or committing any `.md` file, read `Rules/00 - Rules Index.md` and `Rules/10 - Agent and AI Assistant Protocol.md` in full, and follow every rule note under `Rules/` that's relevant to your change.

A mechanical check (`scripts/lint_vault.py`, wired via `.githooks/pre-commit` and `.github/workflows/vault-lint.yml`) rejects non-conforming notes on commit/push — fix the note, don't bypass the check.

See `CLAUDE.md` for the condensed pre-commit checklist.
